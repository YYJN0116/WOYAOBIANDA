# Fitness Coach 项目报告

更新时间：2026-11-04

## 1. 项目是什么

Fitness Coach 是一个移动端健身教练应用原型，目标是根据用户的身体资料、训练目标、训练经验和可用器械，生成更容易执行的训练计划。

当前产品优先解决“今天练什么、为什么推荐这个动作、怎样开始训练”这几个问题，先以背部训练作为第一批可用场景。

## 2. 使用什么应用和技术

- **运行平台**：Android、iOS，并兼容 Web 预览
- **应用框架**：Expo SDK 58
- **界面技术**：React Native、React 19、TypeScript
- **导航方式**：Expo Router 文件路由
- **状态与数据**：本地 TypeScript 数据和业务逻辑；项目已安装 AsyncStorage，但持久化尚未完整接入
- **构建方式**：Expo Go 用于快速预览，后续可使用 EAS Build 构建正式安装包

## 3. 目前已经完成

### 用户流程

1. 欢迎页
2. 健身资料填写
3. 身体部位选择
4. 训练目标和器械选择
5. 生成训练计划
6. 进入训练过程
7. 查看训练结果和训练总结
8. 查看单个动作详情

### 推荐逻辑

- 当前支持背部训练
- 支持背部宽度、背部厚度和背部综合三个目标
- 按训练经验筛选动作
- 按可用器械筛选动作
- 初学者优先推荐更容易控制的器械动作
- 为推荐动作生成训练理由，并显示主要刺激肌群
- 动作数据包含组数、次数、休息时间、说明和安全提示

### 工程基础

- 已按页面、组件、数据、业务逻辑和类型进行分类
- 已配置深色模式
- 已配置 Android、iOS 图标和启动图资源
- 已启用 Expo Router typed routes 和 React Compiler 实验配置
- 已添加第三方许可证说明

## 5. 总体目标

将当前原型发展为一个可靠、易用的个性化健身助手：

1. 扩展完整的身体部位和动作库
2. 建立可保存、可追踪的训练记录
3. 根据历史表现动态调整训练计划
4. 支持账号和多设备同步
5. 增加计时、提醒、动作指导和安全反馈
6. 建立测试、监控和发布流程
7. 最终发布 Android 和 iOS 正式版本

## 6. 接手开发建议

后续 Agent 或开发者接手时，建议按以下顺序：

1. 阅读 `AGENTS.md` 和本报告
2. 运行 `npm install`
3. 运行 `npx expo lint` 和 `npx tsc --noEmit`
4. 使用 `npx expo start` 检查主要页面流程
5. 优先补充训练记录持久化，再扩展其他身体部位

当前项目属于“核心流程已搭建、推荐逻辑已有、准备进入产品化完善阶段”的状态。
